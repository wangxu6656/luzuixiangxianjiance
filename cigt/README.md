# 香烟滤嘴香线识别系统

面向工业检测流水线的滤嘴香线视觉检测软件。从滤棒底部拍摄，识别滤嘴中的香线（芯线），
计算芯线相对滤棒圆心的偏移距离，与设定阈值比较，判定合格/剔除，并将剔除信号输出至 PLC。

## 工作原理

```
滤棒进入接收鼓轮 → 接近开关触发相机拍照 → 图像传输至工控机
→ 预处理(滤波/边缘提取) → 椭圆拟合识别滤棒与芯线轮廓 → 计算圆心坐标
→ 计算芯线偏移距离 → 与设定阈值比较 → 超阈值时 PLC 控制高速剔除阀动作
→ 结果实时显示在人机界面 → 历史数据查询与导出
```

软件实现检测算法、判定逻辑、PLC 输出接口与人机界面。

## 功能

- **实时识别**：调用摄像头连续检测，实时显示滤棒椭圆、芯线圆心、偏移距离与合格/剔除判定
- **图片批量识别**：批量处理图片，生成标注图，导出 CSV 结果
- **剔除信号输出**：仿真 / 串口 / UDP / TCP 四种模式，超阈值时向 PLC 发送剔除指令（指令前缀可配置）
- **历史数据**：SQLite 存储每次检测记录，按时间/结果查询，支持 CSV 导出

## 算法流程

1. **滤波**：高斯滤波平滑图像
2. **边缘提取**：Canny 边缘检测 + 形态学闭运算连通边缘
3. **滤棒椭圆拟合**：在边缘图上找最大椭圆轮廓，用 `cv2.fitEllipse` 拟合滤棒，得到圆心与半轴
4. **芯线椭圆拟合**：滤棒内提取低亮度/高饱和像素（香线为深色或彩色斑点），连通域分析后对每个芯线斑拟合椭圆
5. **偏移计算**：芯线圆心与滤棒圆心距离 / 滤棒半径 = 偏移比；结合滤嘴半径(mm)换算毫米偏移
6. **判定**：偏移比超过阈值（默认 25%）→ 剔除；缺香线默认判定剔除（可配置）
7. **输出**：剔除信号发送至 PLC；检测记录写入历史数据库

## 环境与安装

- Python 3.8+
- Windows / Linux / macOS

```bash
pip install -r requirements.txt
```

可选：串口模式需 `pip install pyserial`

## 运行

```bash
python main.py
```

## 测试

```bash
python test_detector.py    # 合成图像自测
python evaluate.py         # 对 picthave(有香线)/picno(无香线) 评估准确率
```

## 目录结构

```
detector/filter_detector.py  核心算法（滤波/边缘/椭圆拟合/偏移判定）
plc/reject_controller.py     PLC 剔除信号输出（仿真/串口/UDP/TCP）
history/storage.py           历史数据 SQLite 存储与导出
ui/main_window.py            主窗口（实时/批量/历史三个标签页）
ui/live_tab.py               实时识别 + PLC 输出 + 实时判据
ui/batch_tab.py              图片批量识别
ui/history_tab.py            历史数据查询与导出
ui/config_panel.py           参数面板（检测/判定阈值/PLC 设置）
main.py                      程序入口
```

## PLC 输出说明

在"实时识别"页的参数面板中配置：

- **输出模式**：`simulate`(仅记录，不接硬件) / `serial`(串口) / `udp` / `tcp`
- **地址/端口**：TCP/UDP 目标
- **串口号/波特率**：串口模式参数
- **指令前缀**：发送内容形如 `REJECT <时间戳>\n`，可按 PLC 协议修改
  `plc/reject_controller.py` 中的 `_build_payload`
